## 🌟 核心特色功能

### 🎮 游戏玩法
- **完整德州扑克规则** - 支持翻牌前/翻牌/转牌/河牌/摊牌全流程
- **智能AI对手** - 4个不同难度级别的AI玩家（简单/中等/困难/专家）
- **实时游戏状态** - 动态显示筹码、底池、当前下注
- **专业级界面** - 美观的牌桌界面，支持多种操作（弃牌/看牌/跟注/加注/全押）

### 🧠 AI分析引擎（核心亮点）
- **蒙特卡洛胜率计算** - 实时计算手牌获胜概率
- **智能决策建议** - 基于胜率和赔率的专业建议
- **底池赔率分析** - 精确计算盈亏平衡点
- **手牌强度评估** - 完整的牌型识别和排名系统
- **可视化分析** - 胜率圆环图和详细数据展示

### 🎯 技术架构
- **SwiftUI + Combine** - 现代iOS开发框架
- **MVVM架构模式** - 清晰的代码组织结构
- **完整牌型评估** - 支持所有扑克牌型（高牌到皇家同花顺）
- **实时数据绑定** - 响应式UI更新
